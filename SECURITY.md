# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability reporting:
<https://github.com/shahbaz242630/agent-x/security/advisories/new> (or the Security tab, then **Report a vulnerability**). Do not open a public issue, pull request or discussion about it.

Please include what you found, where (file, route or address), how to reproduce it, and what an attacker could do with it.

## What happens next

- We acknowledge a report within 3 working days.
- We confirm or rule it out, and tell you which, within 10 working days.
- We fix a confirmed issue as fast as its severity needs, and tell you when the fix is live.
- We publish an advisory once the fix is live, crediting you unless you ask us not to. Please keep the issue private until then.

## Scope

This repository's code and its staging service. The project handles no real money yet. Test only against your own accounts and data, and don't degrade the service for others.
